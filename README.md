# APPEND NOTE.

プロジェクトセカイ日本版のAPPEND楽曲を記録する、非公式の日本語チェックリストです。

README更新日：2026年10月18日  

## 始め方

`APPENDチェックリスト.html` をブラウザで開いてください。アプリのインストールやログインは不要です。

初期収録した153曲のジャケット画像はHTMLに埋め込まれています。新規曲の取得と、更新で追加された曲の外部画像の表示にはインターネット接続が必要です。

## 主な機能

- ジャケット・曲名・APPENDレベルを1行6曲で表示。狭い画面では横スクロールできます。
- 曲名・読みがなで検索。
- あいうえお順、難易度が低い順・高い順に並べ替え。同レベルは読み順です。
- 「クリア」「フルコンボ」「1 GREAT」「ALL PERFECT」のいずれか1つを選択。
- 選択中のボタンをもう一度押すと解除して未記録に戻ります。
- ALL PERFECTを選択したボタンの枠と、ALL PERFECTの集計が1曲以上の場合の集計欄上部を虹色で表示。
- 限定楽曲の追加・除外に合わせて、総曲数と達成数を集計。
- 楽曲の手動追加・訂正、JSONデータの読み込み・書き出し。
- チェックと曲データの自動保存、バックアップ・復元。
- 「新規APPENDを確認・更新」から公開データを取得。

`1 GREAT` は「フルコンボかつGREATが1つ」の記録欄です。各集計欄は、その項目を選択した曲数を表示します。ALL PERFECTを選んでも、クリアやフルコンボの集計には重複して加算しません。

旧版で複数の達成項目を選択していた曲は、ALL PERFECT → 1 GREAT → フルコンボ → クリアの優先順で1つにまとめます。

## 新規APPENDを更新する

1. インターネットに接続します。
2. 上部の「新規APPENDを確認・更新」を押します。
3. 新規曲数・難易度変更数、または変更なしの結果を確認します。

新曲だけでなく、既存曲にAPPENDが追加された場合も一覧へ追加します。配信日時が未来の新曲は追加しません。取得元から一時的に見つからなくなった曲も、自動削除しません。

チェック、手動訂正、表示設定は保持します。手動で訂正済みの曲は、その内容が取得したデータより優先されます。新規曲の限定区分は通常曲として追加するため、必要に応じて「訂正」から変更してください。

更新結果は操作したブラウザに保存されます。HTMLファイルそのものや、他の利用者のブラウザは書き換えません。常時監視・定期取得は行いません。

通信失敗、不正なデータ、保存領域不足の場合は現在の一覧を維持します。取得元への反映遅れやアクセス制限がある場合は、時間を置いて再試行してください。

「公開データ確認日」は取得成功時の日付（日本時間）に更新します。元データ自体の更新日や、ゲーム内での配信確認を保証する日付ではありません。

## 楽曲の追加・訂正と難易度改定

新規登録は「楽曲を追加」、既存曲の変更は各曲の「訂正」から行います。曲名、読み、APPENDレベル、限定区分、ジャケットURL、確認元URLを変更できます。

難易度が改定された場合は、「訂正」→「APPENDレベル」を変更→「保存する」の順で更新します。難易度順の表示も再計算されます。

曲IDはチェック記録を引き継ぐための固定キーです。曲名やレベルの訂正ではIDを変更しないでください。初期収録した「初音ミクの激唱」は、期間限定のFULLver.のAPPENDです。

## 保存とバックアップ

チェック、曲の追加・訂正、取得済み曲データ、表示設定はブラウザの `localStorage` に保存します。

- 「記録をバックアップ」：チェックと曲データ、表示設定をJSONで保存。
- 「記録を復元」：バックアップから現在の保存内容を置き換え。実行前に確認があります。
- 「曲データを書き出す」：現在の曲一覧をJSONで保存。
- 「曲データを読み込む」：同じIDの曲を訂正、新しいIDの曲を追加。データにない曲は削除しません。

別端末・別ブラウザ・HTMLの移動や名前変更では、以前の記録をそのまま使えない場合があります。ブラウザの保存データを削除した場合やプライベートモードでも、記録が残らないことがあります。重要な記録はバックアップしてください。

ローカルHTMLから公開サイトへ移すときも、元のHTMLでバックアップしてから公開サイトで復元します。記録バックアップは自分用に保管してください。

## 編集用データ

`songs.json` は初期収録曲の編集用データです。HTMLを開いたときにこのファイルを自動読み込みする仕組みではありません。反映には画面の「曲データを読み込む」を使います。

例：

```json
[
  {
    "id": "813",
    "title": "at",
    "reading": "あっと",
    "level": 36,
    "limited": false,
    "jacket": "https://storage.sekai.best/sekai-jp-assets/music/jacket/jacket_s_813/jacket_s_813.png",
    "source": "https://github.com/Sekai-World/sekai-master-db-diff"
  }
]
```

`level` は1～50の整数、`limited` は `true` または `false` です。曲名・読みは必須です。曲IDの重複は受け付けません。画像URLを空欄にすると曲名の代替表示になります。

## 初期収録データと限定楽曲

初期収録は153曲で、次の限定6曲を除外すると147曲です。更新や手動追加によって曲数は変わります。限定曲を非表示にしても記録は消えません。

- 初音ミクの激唱（FULLver.）
- プロセカULTIMATE楽曲メドレー
- 周年記念高難易度書き下ろし楽曲メドレー
- さいたま2000
- 幽玄ノ乱
- 初音ミクの消失−劇場版−

初期データには過去の期間限定曲も含まれます。現在ゲーム内で遊べる曲だけの一覧ではありません。
